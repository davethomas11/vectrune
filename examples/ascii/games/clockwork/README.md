# The Thirteenth Bell

A haunted clockwork forest prototype. You are Wick, its last little lamplighter.
Collect three clockseeds, cross the gears and wake the forest's sleeping heart.
Kindly ghosts return you to a checkpoint; collected seeds are never lost.

This is an **unreleased prototype**, not part of Vectrune 0.3.12.
It requires the GIF-backed sprite loader in this worktree.

```sh
cargo build --bin vectrune
target/debug/vectrune ascii run examples/ascii/games/clockwork/forest.rune
```

Requires a 160x48 terminal (160x47 canvas plus the playback footer), running at
30 FPS. Artwork is larger and the room scrolls horizontally. Arrows/A/D move;
Space/W/Up jumps; Down/S brakes; P pauses gameplay and music; M toggles the haunted
D-minor synth theme and effects; R restarts.
Q/Esc/Ctrl-C quits. Use `--mute` if no audio device is available.
There are no save files or time limits.
Ghost hitboxes are inset to their visible bodies; the overhead ghost near the
gate stays clear of the final jump.
Ghosts have bright solid bodies, large dark eyes and a small mouth. The GIF
palette reserves transparency separately so the body remains visible.

Nine original GIFs are loaded once from disk: courier, trees, moon, gears,
floor, clockseeds, ghosts, mist and the heart gate. The scene layers parallax
trees, platforms, actors, mist and HUD in draw order. GIF delays drive sprite
animation; collision uses separate rectangles. The gears rotate visually
but their top collision surfaces stay still. Movement accelerates smoothly and
retains horizontal momentum throughout a jump, even if pressing Space interrupts
the terminal's arrow repeat. A four-frame jump buffer and coyote window forgive
slightly early/late jumps; opposite arrows steer in the air. Ordinary terminal
input has no reliable key-up events: ground movement expires after a short repeat
grace period and decelerates; Down/S stops immediately, including in the air.
Quicker acceleration and a slightly faster jump/descent keep the earlier jump
height while reducing hang time. Pausing freezes gameplay and music, not the
host's GIF animation clock.

The theme uses `@AsciiMusic/forest_theme` with two bars of `lead:` and `bass:`
notation, not individual frequency declarations. `music "forest_theme"` starts
it; `music.pause`, `music.resume` and `music.stop` control it. This reuses the
Rune-Web music parser, scheduler and native synth. Jump/chime/ghost sweeps remain
`@AsciiTone` effects.

The small pixel artwork is original and generated by `build_assets.py`.
Source GIFs are drawn at 4x design resolution (for example, Wick is 48x80)
with cloak folds, lantern detail, bark, gear rivets, moon craters and gate runes.
The larger view scales scene positions by 4/3 and uses larger decoded sprites
(Wick is 11x9 cells). Physics and collision bounds remain in the original world
coordinates, preserving jump timing and movement feel. The reserved transparency index keeps opaque artwork
separate from transparent background.
The checked-in GIFs need no Python at runtime. To regenerate:

```sh
python3 examples/ascii/games/clockwork/build_assets.py
```

Asset rebuilding requires Pillow. Edit the GIFs directly to replace the artwork.
Pass an asset name to rebuild only that GIF, for example
`python3 examples/ascii/games/clockwork/build_assets.py ghost`.
