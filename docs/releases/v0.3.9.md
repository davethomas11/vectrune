# Vectrune 0.3.9 — Portable syntax, persistent data, simpler hosting

This release brings object syntax across Vect, backend Rune and Rune-Web,
introduces experimental Rune DB and Vect Event providers, and makes it possible
to run a database and frontend together with one command.

## Language parity

- Object property shorthand, replication and grid generators, local templates,
  overlays, matching-object lookups and compound updates across supported hosts.
- Shared expression handling and conformance examples for native and browser
  runtimes, with updated language and library documentation.

## Rune DB and Vect Event

- Reusable `@DataSource` providers for persistent documents and ordered events.
- Native persistence using redb and MessagePack, with browser-local IndexedDB
  and remote HTTP adapters using the same operation packets.
- Atomic document/event batches, revision checks, numeric mutations, bounded
  prefix scans, event replay and long-poll tailing.
- `vectrune db` and `vectrune events` commands for local files, configured
  providers and standalone servers.

Storage remains experimental. This first version does not include SQL, automatic
replication, retention tooling, consumer groups or exactly-once delivery.

## One-command hosting

Run a database and Rune-Web frontend on one server and origin:

```sh
vectrune examples/data/storage/fullstack/single-server.rune
```

Or keep independent applications on separate ports in one process:

```sh
vectrune examples/data/storage/fullstack/app.rune \
  --secondary-app examples/data/storage/fullstack/database.rune
```

`--secondary-app` is repeatable; Ctrl-C stops the group and `--watch` reloads it.
Host/port overrides apply to the primary app. The split storage example accepts
both `localhost` and `127.0.0.1` browser origins. The same-server example uses a
relative endpoint and needs no CORS configuration.

The fullstack example now has a responsive note editor, atomic view counter,
readable event cards and clearer instructions. Default Rune-Web favicons are
self-contained, eliminating requests for missing icon assets.

## Examples and documentation

Examples are organized into `beginner/`, `games/`, `rune-web/`, `api/`, `data/`,
`language/`, `deployment/`, `vect/`, `vectrune/` and `testing/`. Update scripts
that use the previous example paths; see `examples/README.md` for the new index.
Existing public teaching-site URLs are preserved.

The site documentation, library reference and offline man pages include the new
syntax and storage walkthroughs. A downloadable storage example bundle includes
the same-server and split-server apps, atomic checkout and resumable replay.

## Windows source-tooling note

When generating manuals from the tagged sources on Windows, enable Python UTF-8
mode (`PYTHONUTF8=1`). The downloaded Windows binary and bundled manuals are
unaffected. Follow-up documentation encoding and CRLF test-fixture fixes are
[available on main](https://github.com/davethomas11/vectrune/commit/d0344b4).
