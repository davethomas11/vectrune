# Vectrune 0.3.11 — Fetch options, batch reads, and VectRaiders

- **HTTP requests.** Pass `options request_options` to `fetch` or `fetch-json` in native Rune and Rune-Web. Configure request headers, a total timeout in milliseconds, a response size cap, and redirect handling. Requests with custom headers reject redirects so those headers stay on the original request.
- **Rune DB batch reads.** Use the `get_many` packet or `vectrune db get-many` to read multiple keys in one snapshot. Results follow the input order, including duplicate keys and `null` for missing records.
- **Portable generator shorthand.** A named overlay resolves the exact name first and then tries its `_batch` binding. This restores all 18 aliens in [VectRaiders](https://vectrune.com/games/) and works across Vect, backend Rune, Rune-Web, and the browser emulator.
