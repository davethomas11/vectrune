# Vectrune 0.3.12 — ASCII Animator and Neon Circuit

## ASCII Animator

Build native terminal screensavers, animated scenes, live graphs and games with
`@App type = ascii-animator`, `@AsciiAnimator`, `@AsciiSprite`, and shared
`@Logic` initialize/tick actions. Optional `@Ascii3D` adds textured raycast walls,
perspective floor/ceiling and depth-tested billboard sprites. Named `@AsciiTone`
cues reuse the native game synth without sound files.

```sh
vectrune ascii generate --text "Hello!" -o animation.rune
vectrune ascii run animation.rune
vectrune ascii image photo.png --width 80
vectrune ascii image animation.gif --play
vectrune ascii image animation.gif --rune -o animation.rune
vectrune ascii text "VECTRUNE" --font compact --char "*"
```

Generators work without an example directory. `ascii run` runs local files;
examples are not embedded, and there is no `ascii demo` or `ascii list`.
`--plain` produces a silent final-frame capture; `--frames`, scripted `--keys`,
and repeated `--commands` support deterministic playback. `--mute` skips the
audio device. Fonts include bitmap, compact and double-size, with configurable
foreground/background characters. Generator `-o` output never overwrites files.

`ascii image --play` plays composited GIF frames in the terminal with Space
pause/resume. `--rune` exports a self-contained executable Rune animation.
GIF delays are rounded to 60 Hz ticks; both modes loop continuously regardless
of the original loop count. Animated modes accept up to 120 frames, 80 rows
and 8 MiB of ASCII frames. Default GIF conversion still emits only the first frame.

The downloadable example collection includes screensavers, a simulated telemetry
dashboard, Paddle, Meteors, Sentinel, Endless Halls and Descent.
**The Kingdom of Borrowed Mornings** is a complete original typed-command
adventure with nine animated areas, inventory puzzles, hints, a journal, title
music and a sunrise ending. It requires a 78x30 terminal; saves are not implemented.

## Neon Circuit and Pixel 3D

[Neon Circuit](https://vectrune.com/neon-circuit/) joins the teaching site's
play-and-source showcases, with one stable same-origin standalone URL for
campaign saves across locales and embedded/standalone play.

Axel takes on twelve rogue robots: six intro sectors unlock weapons and skills,
then six master sectors combine them. Boss victories tilt the world onto a glass
return deck. Intro returns are overhead; master returns transition into first
person. Each sector has its own return encounter. The five-room finale changes
perspective and ends with the Conductor, a mechanical dragon.

The campaign demonstrates enhanced neon lighting, glass tint, bloom, contact
shadows, haze, animated models, cinematic camera transitions and colored sector
accents. Choose Enhanced or Standard lighting without changing resolution.
Chunked CPU voxel rendering culls open space while preserving color/depth behavior.
Weapon-wheel selection pauses gameplay; campaign progress is saved locally.

## Editing, navigation and audio

- Rune Studio adds workspace/song editing improvements and note selection,
  cut/copy/paste workflows.
- Rune-Web navigation can bind URL fragments to state, and homepage section
  links stay synchronized with the menu.
- Synth tracks gain reverb, delay, filter, bitcrush and chorus effects, alongside
  voice-envelope and music-transition fixes.
- Shared action control flow includes `switch` as a `match` alias.

## Compatibility and packaging

ASCII features are native-terminal only, not browser, HTTP or Lambda hosts.
Ascii3D is fixed-height 2.5D raycasting, not polygon or slope physics.
Linux source builds now need ALSA development headers (`libasound2-dev` on
Debian/Ubuntu). Release builds link a target-specific static ALSA backend and
include its license plus a rebuild source archive. Static musl cannot load
external ALSA plugins; plugin-only device configurations may need the GNU build
or `--mute`. macOS and Windows use system audio backends.

The versioned `vectrune(1)` and `vectrune-language(7)` offline manuals include
the ASCII CLI generators, playback options and language declarations, and
are bundled in every platform release archive.
