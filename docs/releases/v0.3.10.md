# Vectrune 0.3.10 — Marble Run, Dog Walker, and Pixel 3D

[Play Marble Run](https://vectrune.com/marble-run/) to try six downhill courses above the floating Cloudworks factory. Roll through corners and half-pipes, jump gaps and spikes, and spend charge cells to blast sentries. The game saves unlocked courses.

- **Pixel 3D models.** Define spheres by radius, cylinders by radius and height, and ramps by their dimensions. Models support depth testing and pixel dissolve effects. See the [model shape guide](https://github.com/davethomas11/vectrune/blob/main/knowledge/runtime/model-shapes.md).
- **Browser display controls.** Change resolution and palette while playing. Marble Run opens at 576×360 in the Pocket palette, which adds dark silhouettes so the marble, track edges, and obstacles stand out.
- **Experimental WebGL 2.** Marble Run can switch between software rendering and a GPU renderer with model instancing. Try 30 FPS, 60 FPS, or display refresh without changing the simulation's tick rate. The page shows the active renderer and actual FPS.
- **Floating scenery.** An optional lower sky color replaces the floor with a gradient and two drifting layers of clouds.
- **Dog Walker.** [Play the neighborhood arcade game](https://vectrune.com/dog-walker/) in the Blue Pocket palette. Score at lawns and lampposts, avoid traffic and angry neighbors, catch a runaway dog, and finish with fetch at the park.
- **Pixel 3D tethers.** Scenes can render round, depth-tested tethers between state-driven points. Dog Walker uses a two-point tether with slack for its leash. See the [3D tether guide](https://github.com/davethomas11/vectrune/blob/main/knowledge/runtime/pixel3d.md#3d-tethers).
- **Teaching site.** The expandable desktop navigation and mobile accordion group the guides and games. The Games slideshow previews all nine showcases, and the [release history](https://vectrune.com/releases/) is rendered from JSON data.
- **CI.** The Starfall test harness uses compact expression scopes, and the Marble Run cell-limit test checks the limit directly to reduce Intel macOS runner time.
