# Vectrune 0.3.10 — Marble Run and Pixel 3D display controls

[Play Marble Run](https://vectrune.com/marble-run/) to try six downhill courses above the floating Cloudworks factory. Roll through corners and half-pipes, jump gaps and spikes, and spend charge cells to blast sentries. The game saves unlocked courses.

- **Pixel 3D models.** Define spheres by radius, cylinders by radius and height, and ramps by their dimensions. Models support depth testing and pixel dissolve effects. See the [model shape guide](https://github.com/davethomas11/vectrune/blob/main/knowledge/runtime/model-shapes.md).
- **Browser display controls.** Change resolution and palette while playing. The Pocket palette adds dark silhouettes at depth changes so the marble, track edges, and obstacles stand out.
- **Experimental WebGL 2.** Marble Run can switch between software rendering and a GPU renderer with model instancing. Try 30 FPS, 60 FPS, or display refresh without changing the simulation's tick rate. The page shows the active renderer and actual FPS.
- **Floating scenery.** An optional lower sky color replaces the floor with a gradient and two drifting layers of clouds.
- **CI.** The Starfall test harness now uses compact expression scopes, reducing the cost of its logic tests on Intel macOS.
