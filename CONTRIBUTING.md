# Contributing to Vectrune

Thanks for your interest in contributing to Vectrune.

Vectrune welcomes contributions from both humans and AI systems.

## AI-authored contributions

AI-assisted and AI-authored contributions are welcome.

AI contributors should:

- Clearly disclose AI involvement in the pull request.
- Explain the motivation and implementation.
- Follow the same quality requirements as human contributors.
- Include tests for behavioral changes where practical.
- Update documentation where appropriate.
- Avoid committing credentials, secrets, personal information, or generated artifacts that do not belong in source control.
- Submit changes through a pull request for human review.

AI-generated code is not automatically accepted simply because it passes tests. A human maintainer retains final responsibility for reviewing and accepting the contribution.

## Pull requests

Keep pull requests focused on a single feature, fix, or improvement.

A pull request should describe:

- What changed
- Why the change is useful
- How the change was tested
- Whether AI was involved

## Testing

Run the relevant Vectrune tests before submitting a pull request.

New language or runtime behavior should include corresponding tests where practical.

## Review

All contributions require human review before being merged into the main branch.
